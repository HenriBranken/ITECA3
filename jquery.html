Using .each()

This example creates a jQuery object containing all of the list items from the page.

The .each() method is then used to loop through the list items and run an anonymous function for each item.

The anonymous function takes the value from the id attribute on the <li> and adds it to the txt in the list item.

            
                $(function() {
                    // A jQuery object containing all the <li> elements of interest.
                    $('ul#eg8>li').each(function() {
                        // We can access the current element using the this keyword. Extract the value of its 'id' attribute.
                        let theId = this.id;
                        // In italics, display the value of the 'id' attribute next to the <li> content.
                        // $(this) allows us to use jQuery methods on the current element.
                        $(this).append(' <span><em>' + theId + '</em></span>');
                        });
                    });

Events

In this example, when the mouse moves over a list item, the content of its id attribute is written into the list item.

The mouseout event also removes this extra information from the page to prevent content building up.

            
                $(function() {
                    let ids = '';
                    // Identify the <li> elements that we are interested in.
                    let $listItems = $('ul#eg9>li');
                
                    $listItems.on('mouseover', function() {
                        // Extract the 'id' metadata from the <li> element.
                        ids = this.id;
                        // Remove any <span> elements to prevent text from cluttering up.
                        $listItems.children('span').remove();
                        // After the <li> item, display the 'id'.
                        $(this).append(' <span>' + ids + '</span>');
                    });
                
                    // When when mouseout from the <li> element, remove the <span> element that was created.
                    $listItems.on('mouseout', function() {
                        $(this).children('span').remove();
                    });
                });

                    // When we click or mouseover any <li> child of the <ul>:

                    $('ul#eg11').on(

                            listItem = 'Item: ' + e.target.textContent + '
';

Using Animation

In this example, the .animate() method is used to gradually change the values of two CSS properties. The animate property makes it look like the text is sliding to the right as it fades out.

When the user clicks on a list item, it fades out, and the text content slides to the right (which takes 600ms). Once that is complete, a callback function removes the element.

            
                $(function() {
                    // Identify the <li> elements that we are interested in.
                    let $liElems = $("ul#eg13>li");
                
                    // On a 'click' event, make the <li> element transparent, and move the <li> element 100 pixels to the right.
                    $liElems.on('click', function() {
                        $(this).animate({
                            opacity: 0,
                            paddingLeft: '+=100'

                        // The animation should take 600ms to complete.
                        // Finally, the <li> element is removed.
                        }, 600, function() {
                            $(this).remove();
                        });
                    });
                });

Traversing DOM elements

When the page loads, the list below is hidden, and a link is added to the heading that indicates the users can display the list if they wish.

The link is added inside the heading and, if the user click on the link, the <ul> element is faded in.

                $(function() {
                    // Identify the <h3> element we are interested in.
                    let $h3 = $('ul#eg14').prev('h3');

                    // Append an <a> link to the <h3> element.
                    $h3.append('<a class="show">show</a>');
                
                    // When clicking on the element, fade the <ul> in.
                    // Toggle the children with a '.hot' class to have a '.normal' class.
                    $h3.find('a').on('click', function() {
                        $h3.next()
                            .fadeIn(600)
                            .children('.hot')
                            .addClass('normal');
                        
                        // Remove the <a> element.
                        $h3.find('a').fadeOut();
                    });
                });
