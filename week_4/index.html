Conditional Statements

A conditional statement is based on a concept of if/then/else; if a condition is met, then your code executes one or more statements, else your code does something different, or just skips the step.

                
                    // If your score is greater than 50, then you pass, otherwise you fail.
                    if (score > 50) {
                        console.log('You Passed!');
                    } else {
                        console.log('Try again...');
                    }

Switch Statement

A switch statement starts with a variable called the switch value.

Each case indicates a possible value for this variable, and the code that should run if the variable matches that value.

Consider the example below, which generates a message based on the level.

                
                    let message;    // Message
                    let level = 2;  // Level

                    // Determine the message based on the level:
                    switch (level) {
                        case 1:
                            message = 'Good luck on the first test';
                            break;
                        
                        case 2:
                            message = 'Second of Three - Keep Going';
                            break;
                        
                        case 3:
                            message = 'Final round, almost there';
                            break;
                        
                        default:
                            message = 'Good Luck!';
                            break;
                    }
Second of Three - Keep Going

Logical Operators

Comparison Operators usually return single values of true or false.
Logical Operators allow you to compare the results of more than one comparison operator. 

                
                    /*
                        Logical AND.
                        If both expressions evaluate to true, then the expression returns true.
                        If just one of these expressions evaluate to true, then the expression returns false.
                    */
                    value_1 = ((2 < 5) && (3 >= 2));

                    /*
                        Logical OR.
                        If either expression evaluates to true, then the expression returns true.
                        If both return false, then the expression will return false.
                    */
                    value_2 = ((2 < 5) || (2 < 1));

                    /*
                        Logical NOT.
                        This reverses the state of an expression.
                        If it was false (without the ! before it) it would return true.
                        If it was true (without the ! before it) it would return false.
                    */
                    value_3 = !(2 < 1);
value_1 = true
value_2 = true
value_3 = true

            let score1 = 65;  // Round one score

Loops

Loops check a condition. If it returns true, a code block will run. Then the condition will be checked again, and if it still returns true, the code block will run again. It repeats until the condition returns false.

There are three common types of loops:

  • for
  • while
  • do ... while
FOR
If you need to run code a specific number of times, use a for loop. In a for loop, the condition is usually a counter which is used to tell how many times the loop should run.
WHILE
If you do not know how many times the code should run, you can use a while loop. Here the condition can be something other than a counter, and the code will continue to loop for as long as the condition is true.
DO...WHILE
The do...while loop is very similar to the while loop, but has one key difference: it will always run the statements inside the curly braces at least once, even if the condition evaluates to false.
            
                // FOR-loop example.

                // In this example, the scores for each round of a test are stored in an array called scores:
                let scores = [24, 32, 17];
                let roundNumber = 0;
                let msg = '';
                let i;

                // Loop through the items in the array:
                for (i = 0; i < scores.length; i++) {
                    // Arrays are zero-based, therefore we add one to get the round number:
                    roundNumber = i + i;

                    // Write the current round to the message:
                    msg += 'Round ' + roundNumber + ': ';

                    // Get the score from the scores array:
                    msg += scores[i] + '<br>';
                }
                console.log(msg);  // What is `msg`?
Round 1: 24
Round 2: 32
Round 3: 17

                // Set a counter to 1, and initialise a blank string variable.
                let i = 1;
                let msg = '';

                // Store the 5-times table in a variable:
                while (i <= 10) {
                    let multiple = i * 5;
                    msg += `${i} x 5 = ${multiple}<br>`;
                    i++;
                }

                console.log(msg);  // What is `msg`?

2 x 5 = 10
3 x 5 = 15
4 x 5 = 20
5 x 5 = 25
6 x 5 = 30
7 x 5 = 35

                // DO...WHILE-loop example

                // Set a counter to 1, and initialise a blank string variable.
                let i = 1;
                let msg = '';

                do {
                    let multiple = i * 5;
                    msg += `${i} x 5 = ${multiple}`;

Array Methods

Adding Items

            
                // --------------------------------------------------------------------------------------------------------- //
                // push()  Adds one or more items to end of the array, and returns the number of items in it.

                // --------------------------------------------------------------------------------------------------------- //

Splice

The splice() method adds and/or removes array elements.

The splice() method overwrites the original array.

            
                // --------------------------------------------------------------------------------------------------------- //
                let fruits = ['Banana', 'Orange', 'Apple', 'Mango'];
                // At position 2, add 2 elements:
                fruits.splice(2, 0, 'Lemon', 'Kiwi');  // What is `fruits`?

                // --------------------------------------------------------------------------------------------------------- //
                let fruits = ['Banana', 'Orange', 'Apple', 'Mango', 'Kiwi'];
                // At position 2, remove 2 items:
                fruits.splice(2, 2);  // What is `fruits`?

                // --------------------------------------------------------------------------------------------------------- //
                let fruits = ['Banana', 'Orange', 'Apple', 'Mango'];
                // At position 2, add 2 elements, and remove 1 element:
                fruits.splice(2, 1, 'Lemon', 'Kiwi');  // What is `fruits`?
fruits = ['Banana', 'Orange', 'Lemon', 'Kiwi', 'Apple', 'Mango']
fruits = ['Banana', 'Orange', 'Kiwi']
fruits = ['Banana', 'Orange', 'Lemon', 'Kiwi', 'Mango']

Maps

A map holds key/value pairs, where the keys can be of any datatype.

            
                // Map Creation
                let fruits = new Map([
                    ['apples', 500],
                    ['bananas', 300],
                    ['oranges', 200]
                ]);

                // Map Creation
                let classes = new Map([
                    ['grade_1', 40],
                    ['grade_2', 35],
                    ['grade_3', 41]
                ]);

                // --------------------------------------------------------------------------------------------------------- //
                // has()  Returns true if a key exists in a Map.
                let value_1 = fruits.has('apples');  // What is `value_1`?

                // --------------------------------------------------------------------------------------------------------- //
                // get()  Gets the value for a key in a Map.
                let value_2 = fruits.get('apples');  // What is `value_2`?

                // --------------------------------------------------------------------------------------------------------- //
                // delete()  Removes a Map key/value pair specified by a key.
                fruits.delete('apples');  // What is `fruits`?

                // --------------------------------------------------------------------------------------------------------- //
                // clear()  Removes all the elements from a Map.
                classes.clear();  // What is `classes.size`?
value_1 = true
value_2 = 500
classes.size = 0

Iterating Over Maps

            
                // Map Creation
                let classes = new Map([
                    ['Grade 1', 40],
                    ['Grade 2', 35],
                    ['Grade 3', 42]
                ]);

                // --------------------------------------------------------------------------------------------------------- //
                // Iterating over key/value pairs.
                for (let [k, v] of classes) {
                    console.log(`${k} has ${v} students.`);
                }
                /* Output:
                Grade 1 has 40 students.
                Grade 2 has 35 students.
                Grade 3 has 42 students.
                */

                // --------------------------------------------------------------------------------------------------------- //
                // Iterating over key/value pairs.
                for (let [k, v] of classes.entries()) {
                    console.log(`${k} has ${v} students.`);
                }
                /* Output:
                Grade 1 has 40 students.
                Grade 2 has 35 students.
                Grade 3 has 42 students.
                */

                // --------------------------------------------------------------------------------------------------------- //
                // Iterating over keys.
                for (let k of classes.keys()) {
                    console.log(k);
                }
                /* Output:
                Grade 1
                Grade 2
                Grade 3
                */

                // -------------------------------------------------------------------------------------------------------- //
                // Iterating over values.
                for (let v of classes.values()) {
                    console.log(`${v} students.`);
                }
                /* Output
                40 students.
                35 students.
                42 students.
                */
